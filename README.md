# Vaccination EDA Project

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA) of vaccination and public health data**. The main objective is to understand vaccination coverage, vaccine schedules, vaccine introductions, disease incidence, and reported cases using data analysis and visualization techniques.

The analysis helps identify important patterns, trends, relationships, and areas that may require attention for better vaccination planning and public health management.

## 🎯 Business Objective

The objective of this project is to analyze vaccination-related data and provide meaningful insights that can help improve:

* Vaccination program monitoring
* Vaccine planning and resource allocation
* Identification of low vaccination coverage areas
* Understanding disease incidence and reported cases
* Analysis of vaccine schedules and target populations
* Public health decision-making

## 📂 Datasets Used

The project includes the following datasets:

1. **Coverage Dataset**

   * Vaccination target numbers
   * Doses administered
   * Vaccination coverage

2. **Incidence Rate Dataset**

   * Disease incidence rates
   * Disease information
   * Year and region details

3. **Reported Cases Dataset**

   * Reported disease cases
   * Disease and regional information

4. **Vaccine Introduction Dataset**

   * Vaccine introduction information
   * Country and WHO region
   * Year of introduction

5. **Vaccine Schedule Dataset**

   * Vaccine schedules
   * Target population
   * Geographic area
   * Age administered
   * Schedule rounds
